# 附录 · Go 原版速查与移植对照

> **定位**：查阅型附录。主线开发不需要读 Go；当你想确认某条规格的原始出处，
> 或好奇"原版是怎么实现的"时，从这里进。

## 2. Go 语法 → Java 30 秒对照

| 你会在原版看到 | 含义 | Java 对应 |
|----------------|------|-----------|
| `func (s *Svc) M() error` | 接收者 = this | 实例方法 |
| `x, err := f()` + `if err != nil` | 错误是返回值 | try/catch（提前 return ≈ throw） |
| `json:"video_id"` / `gorm:"unique"` | struct tag（反射元数据） | `@JsonProperty` / `@TableField` |
| `json:"-"` | 永不序列化 | `@JsonIgnore` |
| `nil` 判断后 `= []T{}` | 空切片防 JSON null | 集合初始化空列表 |
| `defer f.Close()` | 函数退出必执行 | finally / try-with-resources |
| `go f()` | goroutine | 线程池 submit |
| `chan` + `select` | 阻塞队列 + 多路等待 | BlockingQueue + 轮询 |
| `ctx` 参数 + `WithTimeout(50ms)` | 取消/超时贯穿 | 客户端 timeout 配置 |
| `singleflight.Do(key, fn)` | 同键并发合并 | Caffeine LoadingCache |
| `errors.Is/As` | 错误分类 | catch 特定异常类型 |
| `sync.Mutex / RWMutex` | 锁 | synchronized / ReadWriteLock |
| `regexp.MustCompile` | 编译正则 | `Pattern.compile` |
| `time.Time.Unix()/UnixMilli()` | 秒/毫秒时间戳 | `Instant.getEpochSecond/toEpochMilli` |
| 表名 = 结构名复数下划线 | GORM 约定 | 你手工建表，无此约束 |

## 3. 读原版的三条规矩

1. **入口永远从 `http/router.go` 找**——有 handler 没路由的是死代码（如 DeleteVideo）。
2. **字段名以 struct tag 为准**，README/设计文档与代码冲突时信代码。
3. **原版历史包袱不要当规格**：业务错误默认 500、`expected/actual` 命名反了
   （见《04》警告块）、refresh 兜底全表扫描——这些在对应阶段文档里都标了处理方式。

## 4. 规格出处声明

各阶段文档里的接口契约、表结构、缓存 key 与消息语义，2026-09-03 由逐条源码核实（含运行实测：SSE 帧、
分块状态机、Range、计数链路）。想复核某条时：按第 1 节导航找到文件，用第 2 节对照表读懂。

## 5. 阶段 2 参考：原版启动顺序与配置出处（从《02》移来，备查）

原版 API 进程（`backend/cmd/main.go`）的初始化顺序，你实现降级逻辑时可对照：

| 步骤 | 原版行为 | 失败时 |
|------|---------|--------|
| 1 加载配置 | YAML + 环境变量覆盖 | 缺失用内置默认 |
| 2 连 MySQL | 打开连接池 | **直接退出进程** |
| 3 自动建表 | AutoMigrate 10 个实体（Java 版没有这一步，DDL 在各阶段第 1 步手工执行） | 退出 |
| 4 连 Redis | Ping 300ms | 只记日志，缓存整体禁用 |
| 5 连 RabbitMQ | TCP 拨号 | 只记日志，异步退回同步 |
| 6 注册路由并监听 | Gin :8080 | — |

原版配置文件 `backend/configs/config.compose-local.yaml` 的键：
`server.port`、`database.{host,port,user,password,dbname}`、`redis.{host,port,password,db}`、
`rabbitmq.{host,port,username,password}`；环境变量 `SERVER_PORT`、`MYSQL_*`、`REDIS_*`、
`RABBITMQ_*`、`JWT_SECRET`（密钥不在 YAML 里，只来自环境变量）。
